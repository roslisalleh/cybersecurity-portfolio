
# Wireshark Network Traffic Analysis

## Objective
To analyse network packets using Wireshark.

## Tools
- Wireshark
- Windows or Linux

## Activities
1. Capture network traffic.
2. Apply ICMP and DNS display filters.
3. Examine source and destination IP addresses.
4. Identify relevant protocol fields.

## Learning Outcome
Understand how to analyse network protocols
and investigate network communication.
